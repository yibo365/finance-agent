# 决策框架 PPT 方法论

## 产物定位

给"要做决策的读者"：10 页以内讲清框架与结论，每页信息可回溯（页脚 ev-* 标记），
末页自动附完整溯源清单。页数与结构完全由任务决定，不套固定页数。

## 结构组织建议（按任务裁剪）

1. title 页：结论式标题（不要"关于XX的分析"这种题目，直接给判断）；
2. section 页分隔大章节（如"框架"/"证据"/"结论与边界"）；
3. bullets 页：每页一个论点 + 3-5 条支撑，一页只说一件事；
4. table 页：对照类内容（如 黄金 vs 比特币 的多维对比矩阵）用表格版式，
   table_headers + table_rows；
5. 收尾页：结论、适用边界与反例条件（什么情况下该结论失效）。

## 纪律

- 每页 evidence_refs 挂本页论据的溯源 id（渲染成页脚标记）；
- 数字必须与 Excel 底稿一致——引用底稿的汇总口径，不另算一套；
- notes 字段写补充说明（渲染进页脚），不要把讲稿塞进 bullets；
- 不做投资建议式措辞（"应买入"），用研究判断措辞（"相对更符合避险特征"）。

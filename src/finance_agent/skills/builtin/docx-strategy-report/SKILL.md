# 策略报告方法论

## 产物定位

给"要完整论证过程"的读者：报告正文每个含数字/事实的段落带 ev-* 上标标记，
文末"溯源明细"附录列出全部来源 URL 与抓取时间——他人可复核甚至复抓。

## 结构组织建议（按任务裁剪，不是固定模板）

1. 摘要（heading + narrative）：核心结论 3-5 句，先给判断再给依据；
2. 研究设定：数据（标的/区间/来源/对齐口径）、方法（指标定义、比较维度）；
3. 主体章节按论证逻辑组织（如：避险属性证据 → 抗通胀证据 → 相关性与组合含义），
   每章 heading + narrative，关键数据用 table；
4. 反面证据与局限性：必须独立成章，写清结论在什么条件下不成立；
5. 结论与观察清单：后续值得跟踪的信号。

## 写作纪律

- "时间吻合 + 影响逻辑"措辞，禁止因果断言；
- 每个含数字的段落挂 evidence_refs；数字与 Excel 底稿/PPT 保持同源一致；
- 引用他方观点须给来源；没有来源支撑的判断明确标注为"本报告观点"；
- 不构成投资建议的声明由渲染器自动加入，不必写进正文。

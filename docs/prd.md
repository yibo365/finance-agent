# PRD：投研 Agent（行情 × 事件对齐分析）

> 版本 v1.2 ｜ 2026-07-03 ｜ 状态：已评审，作为 M1–M8 开发依据
> v1.1：多轮会话/产物版本/Web 薄层；v1.2：工作区文件安全边界（无沙箱取舍）

## 1. 背景与问题

投研/行业研究场景中，研究员经常需要回答"**这段行情为什么这么走**"：把一段时间的行情走势与同期行业大事件对齐，判断事件对标的的影响，并产出一份**他人能复核、能点进去溯源**的交付物。

现状痛点：

- 行情数据、资讯事件散落在不同工具里，人工对齐费时且易漏；
- 分析结论常以截图/口头形式传递，**无法回溯"这个结论基于哪条原始数据"**；
- 产物形态多样（网页、Excel 底稿、PPT、Word 报告），每种都要重复劳动。

## 2. 产品目标

构建一个 agent，接收**自然语言描述的研究任务**，自主完成：

1. 采集行情数据（OHLCV）与同期行业资讯；
2. 用确定性算法识别行情变化点（拐点、加速、下跌、上涨）；
3. 研究并筛选同期大事件，评定影响等级，与行情变化点做吻合性对齐；
4. 生成**可交互、可溯源**的研究产物（HTML / Excel / PPT / Word）。

### 非目标（Non-goals）

- 不做投资建议或收益预测；产物是研究底稿，不是荐股报告。
- 不做实时行情/流式更新；单次运行产出静态产物。
- 不追求事件因果的统计显著性检验；对齐是"时间吻合 + 逻辑论证"级别的研究辅助。
- 不做多用户/服务化部署；本项目交付单机 CLI。

## 3. 目标场景（验收用例）

### 场景 A：单标的事件对齐 K 线报告

> "回顾英伟达（NVDA）近五年行情数据（开盘价、收盘价、最高价、最低价、成交量），梳理同期 AI 行业大事件（如 ChatGPT 发布、B100 芯片发布、DeepSeek 等），在 K 线图上标记行情变化触发时刻的主要事件、影响评级，产物可交互、可溯源，最终生成一个 HTML。"

**产出**：`outputs/` 下一个可双击打开的 HTML。

### 场景 B：双资产比较分析体系

> "请构建黄金与比特币作为避险/抗通胀资产的可交互比较分析体系，产物包括 Excel 回测底稿、PPT 决策框架、Word 策略报告。"

**产出**：`outputs/` 下 xlsx + pptx + docx 三件套，本地 Office/WPS 可打开。

两个场景**共用同一个 agent 与同一条流水线**，差异只在任务解析出的标的、资讯关键词与所选产物 skill——这是"自主完成这类任务"的核心验证点。

## 5. 产物质量要求

**结构灵活性**（前提要求）：用户任务多种多样，产物的章节构成、PPT 页面构成、Excel sheet 构成**不预设固定模板**，由 agent 按任务内容经 ArtifactSpec 中间表示（见技术设计 §6）动态决定；skill 只提供渲染骨架与组件库（K 线交互外壳、文档样式集），不提供内容模板。

**可交互**的定义：

- HTML：K 线可缩放平移、悬浮显示 OHLCV、事件标注可点击展开详情、图例可开关；
- Excel：指标由公式计算而非写死数值，修改参数单元格可联动重算；
- PPT/Word：本地正常打开、目录/结构完整（交互性要求低于前两者）。

**可溯源**的定义：

- 任何呈现给读者的"事件"必须带可点击的原始来源 URL；
- 任何"拐点/变化"标注必须能回指原始 OHLCV 数据行与触发规则；
- 数据抓取时间、数据源、查询词记录在案，他人可复核甚至复抓。

## 6. 约束

- **密钥安全**：密钥为 LLM 供应方密钥（`OPENAI_API_KEY`，任何 OpenAI 兼容网关经 `OPENAI_BASE_URL` 指定）与联网搜索密钥（`TAVILY_API_KEY`），走环境变量/.env（gitignore）或 Web 设置弹窗（写回本机 .env），不入库、不出现在任何产物中；
- **数据源免 key**：行情与资讯源全部选用无需注册密钥的公开接口，保证评审者可复跑；
- **前端依赖安全与跨域**：HTML 产物不引用 CDN，Plotly 本地 vendor 随产物分发；数据内嵌，双击 file:// 打开即可用，无跨域请求；
- **文件安全（无沙箱取舍）**：时间盒内不引入 OS 级沙箱（容器/seccomp），代之以应用层约束——LLM 只传逻辑标识（artifact_id/dataset_id）不传路径、WorkspaceFS 路径守卫、版本文件 append-only、注册表原子写；产物不含可执行内容。若未来需要执行用户自定义代码（如自定义指标脚本），必须补真沙箱，属明确的范围外；
- **时间盒**：4–8 小时，AI Coding 辅助开发，过程记录入 `docs/ai-process.md`。

## 7. 验收标准

1. `uv sync && cp .env.example .env`（填 key）后，两条场景命令均能端到端跑通；
2. 场景 A 产出的 HTML 满足第 5 节全部"可交互/可溯源"定义；
3. 场景 B 产出三件套且 Excel 公式联动可用；
4. 事件标注与拐点时间窗口吻合（±数个交易日内），且每个高影响事件的评级有论证文字；
5. `uv run pytest` 与 `node --test tests/*.test.cjs` 全绿；
6. 仓库内 `git grep` 不到任何真实密钥；HTML 产物断网可打开；
7. 多轮修改：场景 A 产物生成后，会话内追加修改指令（如调整某事件评级、新增分析章节），产物升为 v2 且改动**定点生效**（未涉及部分不变），v1 文件仍可打开对照；关闭进程后 `--resume` 恢复会话仍能继续修改；
8. Web 界面（P1）：本地启动后能完成与 REPL 等价的对话，并在产物面板看到 manifest 中的产物与版本；
9. 文件边界：路径穿越（`..`）、绝对路径、符号链接逃逸类输入被 WorkspaceFS 拒绝（有单测覆盖）；任何一次运行生成的文件只出现在该会话工作区目录内。

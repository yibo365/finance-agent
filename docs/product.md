# 产品文档：finance-agent 投研工作台

> 三篇文档的分工：本篇讲**做什么、为什么**；[technical.md](technical.md) 讲**怎么用、怎么改**；
> [architecture.md](architecture.md) 讲**为什么这样设计**。AI 辅助开发过程见 [ai-process.md](ai-process.md)。

## 1. 定位

一个本地运行的投研 Agent 工作台：用户以自然语言提出研究任务（"回顾英伟达近五年行情，
梳理 AI 大事件，生成 HTML"），系统自动完成 **行情采集 → 变化点检测 → 事件研究 →
拐点×事件对齐 → 产物生成** 的完整流水线，产出可交互、可溯源的研究产物
（HTML / Excel / PPT / Word），并支持多轮对话式的增量修改。

核心主张：

- **可溯源**：每个结论、事件、拐点都持有 evidence 回链（来源 URL、抓取时间、原始摘录），
  产物内可逐级回查——不可回溯的结论不允许进产物；
- **可交互**：HTML 报告是自包含的交互式 K 线（缩放/悬浮/事件点击展开）；Excel 底稿
  全公式驱动（改参数联动重算）；
- **可修改**：产物有稳定标识与版本历史，"把 DeepSeek 评级改成高"这类修改走定点变更 +
  重渲染，不重跑研究、不重抓数据；
- **过程可见**：每个 agent 的每次工具调用实时呈现在界面的执行时间线上，长任务不是黑盒。

## 2. 目标场景（验收用例）

**场景 A：单标的事件对齐 K 线报告**。回顾 NVDA 近五年行情，梳理同期 AI 行业大事件
（ChatGPT 发布、B100、DeepSeek 等），在可交互 K 线上标记行情变化点与对应事件、影响评级，
产出自包含 HTML。

**场景 B：双资产比较分析体系**。构建黄金（GC=F）与比特币（BTC-USD）作为避险/抗通胀资产
的可交互比较分析，一次产出三件套：Excel 回测底稿（全公式）、PPT 决策框架（16:9）、
Word 策略报告。

两个场景均可在 Web 界面一句话发起，多轮追问与修改。

## 3. 功能清单（现状）

### 研究流水线

| 能力 | 说明 |
| --- | --- |
| 自然语言任务入口 | Web 聊天为主入口；CLI（REPL / `-p` 一次性）保留为辅助入口 |
| 行情采集 | 日线 OHLCV，多源降级链（Yahoo query1 → query2 → 本地缓存种子），覆盖股票/期货/加密 |
| 变化点检测 | 确定性算法识别趋势拐头/加速/回撤反弹/量能异常，每个点带触发规则与数据窗口 |
| 事件研究 | 三路资讯源：Tavily 联网检索（确定性 API，与 LLM 解耦）、HN Algolia 历史检索、Yahoo 资讯；事件带来源 URL 与影响评级（1-5）+ 方向 |
| 对齐分析 | 时间窗吻合 + 影响逻辑论证；无法解释的拐点如实标注"未找到对应事件"，不强行归因 |
| 产物生成 | HTML（交互 K 线）/ Excel（公式底稿，参数联动，自动年度收益与核心指标）/ PPT（16:9 自绘版式，防溢出自动分页）/ Word（结构化报告，尾注回链） |
| 多轮修改 | 产物按 artifact_id + 版本管理，历史版本全保留；修改走 spec 定点变更 |
| 全链路溯源 | evidence 记录 + 产物回链锚点 + 溯源清单页/表；事件 URL 必须真实出自检索记录（渲染校验拒绝编造） |

### Web 工作台

| 能力 | 说明 |
| --- | --- |
| 多会话聊天 | 类 ChatGPT 三栏布局：会话列表 / 对话流 / 产物面板；会话列表存浏览器 localStorage（单用户设计，服务端不提供会话列表接口） |
| 执行过程时间线 | 每个 agent 的启动/工具调用/结果实时流式呈现，可折叠；历史轮次可回放 |
| 并行任务 | 不同会话可同时运行各自任务；切换会话不中断执行（事件进内存缓冲，切回重放） |
| 运行态与停止 | 运行中输入框禁用、按钮变"⏹ 停止"（真取消：一路取消到 SDK 运行任务）；刷新后自动恢复运行态并轮询收敛 |
| Markdown 回复 | 助手回复渲染 Markdown（表格/代码/链接），经 DOMPurify 净化 |
| 运行时设置 | 左下角设置弹窗：OpenAI 兼容三元组（Base URL + Key + 模型）与 Tavily Key，保存写回 .env，对新会话生效 |
| 产物面板 | 版本历史、在线预览（HTML inline）、下载 |

### 模型与供应方

任何 **OpenAI 兼容** API 即可使用（OpenAI 官方 / OpenRouter / DeepSeek 官方 / Kimi /
自建网关），供应方差异（response_format 支持度、消息邻接校验、max_tokens 上限）
全部由兼容层自动抹平，应用行为与供应方无关。联网检索走 Tavily 独立 API——
换 LLM 不改变检索数据，研究可复现。

## 4. 产物质量要求

- 事件必须带可点击原文 URL，且 URL 必须逐字出自检索记录（渲染做成员校验，编造即拒绝）；
- 指标类数字不允许手写：Excel 全公式（改参数联动），HTML 图表数据来自数据集缓存；
- 叙事用"时间吻合 + 影响逻辑"措辞，不做因果断言、不做投资建议；
- 材料缺口如实声明（coverage_notes / 局限性段落），宁缺毋滥。

## 5. 非目标与边界

- **单用户、本地运行**：仅绑定 127.0.0.1，无鉴权/多用户/远程访问；
- **不做投资建议**：研究判断措辞，不出现"应买入"类表述；
- 会话"删除"仅移出前端本地列表，服务端工作区文件不动（审计优先）；
- 已知边界：中文财经资讯源较薄（实质依赖 Tavily 一路）；行情源为 Yahoo 非官方接口
  （有多源降级但无 SLA）；无真实 LLM 的自动化端到端回归（确定性层全测，
  流水线协议改动需人工跑一次真实任务验收）。
